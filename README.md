# Blog Application

## 📌 Project Overview

This project is developed as part of my **Full Stack Developer Virtual Internship**. The application is a modern blog platform that enables users to create, manage, and interact with blog posts through a user-friendly interface.

The goal of this project is to gain hands-on experience in full stack web development by implementing both frontend and backend technologies to build a complete web application.

---

## 🚀 Features

- User Registration and Login
- Secure Authentication and Authorization
- Create Blog Posts
- Read Blog Posts
- Update Existing Posts
- Delete Posts
- Responsive User Interface
- Search and Filter Blogs
- User Profile Management
- Database Integration
- RESTful API Implementation

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/blog-application.git
```

### Navigate to Project

```bash
cd blog-application
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

## ▶️ Run the Application

### Start Backend Server

```bash
cd backend
npm start
```

### Start Frontend Application

```bash
cd frontend
npm start
```

The application will be available at:

```
http://localhost:3000
```
